Principal Component Analysis (PCA)

Project Title

Dimensionality Reduction and Visualization of the Iris Dataset Using Principal Component Analysis (PCA)

Objective

To apply Principal Component Analysis (PCA) to the Iris dataset to reduce the number of features while preserving important information and visualize the dataset in a lower-dimensional space.

Dataset

Dataset Name: Iris.csv

Library: Pandas, NumPy, Scikit-learn, Matplotlib

Technique: Principal Component Analysis (PCA)

Description

This practical uses PCA to transform the original Iris dataset features into a smaller set of principal components. It helps simplify the dataset, identify patterns, and visualize relationships between Iris flower species.
