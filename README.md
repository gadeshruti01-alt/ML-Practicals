# Machine Learning Practicals

This repository contains Machine Learning practicals implemented using Python and Jupyter Notebook as part of the B.Tech Information Technology curriculum.

## List of Practicals

| No. | Practical Name | Algorithm / Technique |
|---:|---|---|
| 1 | Data Preprocessing | Data Cleaning and Preprocessing |
| 2 | Exploratory Data Analysis | EDA and Data Visualization |
| 3 | Regression Algorithms | Linear Regression and Logistic Regression |
| 4 | Principal Component Analysis | PCA for Dimensionality Reduction |
| 5 | Support Vector Machine | SVM Classification |
| 6 | Decision Tree | Decision Tree Classification |
| 7 | Classification Algorithms | Decision Tree and K-Nearest Neighbors (KNN) |
| 8 | Regression Model Comparison | Linear Regression, Decision Tree Regression, Random Forest Regression |
| 9 | Classification Model Comparison | Logistic Regression, Decision Tree, KNN, SVM, Random Forest |
| 10 | K-Means Clustering | Unsupervised Learning and Customer Segmentation |
| 11 | Single-Layer Artificial Neural Network | ANN-Based Pass/Fail Prediction |

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## How to Run

1. Clone or download this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries.
4. Open the relevant `.ipynb` file.
5. Run the notebook cells in sequence.

## Learning Outcomes

- Understand data preprocessing and exploratory analysis.
- Implement supervised and unsupervised machine learning algorithms.
- Perform classification, regression, and clustering.
- Apply dimensionality reduction using PCA.
- Compare machine learning models using suitable evaluation metrics.
- Understand the basic working of an artificial neural network.
