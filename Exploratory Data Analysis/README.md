Project Title

Exploratory Data Analysis of the Titanic Dataset Using Python

Objective

To explore and analyze the Titanic passenger dataset, identify patterns and relationships between variables, and visualize factors associated with passenger survival.

Dataset

Dataset Name: train.csv

Library: Pandas, Matplotlib, Seaborn

Technique: Exploratory Data Analysis (EDA)

Description

This practical explores the Titanic dataset by examining its structure, summary statistics, missing values, and relationships between passenger attributes. Data visualization techniques are used to understand survival patterns based on features such as passenger class, age, and gender.
