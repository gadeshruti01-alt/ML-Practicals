Mall Customer Segmentation Using K-Means Clustering

Objective

To implement the K-Means Clustering algorithm to group mall customers into different clusters based on their characteristics and spending behavior.

Project Details

Algorithm: K-Means Clustering

Dataset: Mall_Customers.csv

Notebook: Mall_Customer_Segmentation_Using_KMeans.ipynb

Programming Language: Python

Environment: Jupyter Notebook

Description

This project applies the K-Means Clustering algorithm to segment mall customers into groups with similar characteristics. The dataset includes customer information such as age, annual income, gender, and spending score.

The project explores customer data, determines suitable clusters, and visualizes the resulting customer segments to help understand different shopping behaviors.

Technologies Used

Python

Jupyter Notebook

Pandas

NumPy

Matplotlib

Seaborn

Scikit-learn

Learning Outcomes

Understand unsupervised machine learning.

Explore and preprocess customer data.

Apply the K-Means Clustering algorithm.

Select a suitable number of clusters using the Elbow Method.

Visualize and interpret customer segments.
