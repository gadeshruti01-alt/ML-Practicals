Study Hours Pass/Fail Prediction Using a Single-Layer Artificial Neural Network (ANN)

Objective

To implement a Single-Layer Artificial Neural Network (ANN) to predict whether a student will pass or fail based on the number of study hours.

Project Details

Algorithm: Single-Layer Artificial Neural Network (ANN)

Input Feature: Study hours

Output: 0 = Fail, 1 = Pass

Dataset: Created manually within the notebook

Notebook: Study_Hours_Pass_Fail_Prediction_Using_ANN.ipynb

Programming Language: Python

Environment: Jupyter Notebook

Description

This project demonstrates a simple neural network using study hours as input and pass/fail status as output. The dataset is created directly in Python using NumPy arrays.

The model learns the relationship between study hours and student results and uses this pattern to predict whether a student is likely to pass or fail.

Dataset Details

The dataset contains eight study-hour values, from 1 to 8.

Input (X): Number of study hours

Output (y): Student result, where 0 represents Fail and 1 represents Pass

Students studying 1–4 hours are labeled Fail.

Students studying 5–8 hours are labeled Pass.
