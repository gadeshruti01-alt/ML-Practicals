Regression Algorithms Using Python

This folder contains machine learning projects implemented using Python and regression algorithms.

1. House Price Prediction Using Linear Regression

Objective: To predict house prices based on housing-related features using Linear Regression.

Algorithm: Linear Regression

Dataset: USA_Housing.csv

Notebook: House_Price_Prediction_Using_Linear_Regression.ipynb

Libraries: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

Description: This project analyzes housing data and builds a Linear Regression model to predict house prices based on input features.

2. Diabetes Prediction Using Logistic Regression

Objective: To predict whether a person has diabetes using relevant medical attributes.

Algorithm: Logistic Regression

Dataset: diabetes.csv

Notebook: Diabetes_Prediction_Using_Logistic_Regression.ipynb

Libraries: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

Description: This project preprocesses diabetes data, trains a Logistic Regression model, and evaluates its classification performance.
