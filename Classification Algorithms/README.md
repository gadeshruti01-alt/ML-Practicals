Classification Algorithms Using Python

This folder contains machine learning practicals implementing classification algorithms using Python and Scikit-learn.

1. Decision Tree Classification

Notebook: Decision_Tree_Classification.ipynb

Dataset: data.csv

Algorithm: Decision Tree Classifier

Description: This practical uses a Decision Tree to classify breast cancer cases as benign or malignant based on features in the dataset.

2. K-Nearest Neighbors (KNN) Classification

Notebook: KNN_Classification.ipynb

Dataset: data.csv

Algorithm: K-Nearest Neighbors (KNN)

Description: This practical uses the KNN algorithm to classify data based on the nearest neighboring data points.
