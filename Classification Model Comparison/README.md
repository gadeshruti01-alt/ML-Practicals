Breast Cancer Classification Model Comparison

Objective

To implement and compare different classification algorithms for predicting breast cancer diagnosis using Python and machine learning.

Project Details

Dataset: data.csv

Notebook: Breast_Cancer_Classification_Model_Comparison.ipynb

Programming Language: Python

Environment: Jupyter Notebook

Algorithms Used

Logistic Regression

Decision Tree Classifier

K-Nearest Neighbors (KNN)

Support Vector Machine (SVM)

Random Forest Classifier

Description

This project uses the Breast Cancer Wisconsin dataset to classify tumors as benign or malignant based on features such as radius, texture, perimeter, area, smoothness, and other cell characteristics.

Multiple classification algorithms are trained and evaluated on the same dataset. Their performance is compared using metrics such as accuracy, precision, recall, F1-score, and confusion matrix to identify the best-performing model.

Learning Outcomes

Understand different classification algorithms.

Perform data preprocessing and feature selection.

Train and test multiple classification models.

Evaluate models using classification metrics.

Compare model performance and identify a suitable classifier.
